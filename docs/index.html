What this evidence cannot tell you

  • One utterance per setting. This shows the effect is real and large; it is not a benchmark, and the percentages should not be quoted as one.
  • Reading pace was not matched across runs, so emphasis could have influenced which constraints survived. This is the most likely confound and it is uncontrolled.
  • The spoken side is the known script. A separate local ASR engine read the same audio and disagreed with Wispr in both directions, which is itself the reason this has to be measured rather than reasoned about.
  • Audio is not published with this report, because it contains a voice.
