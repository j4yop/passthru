# Build provenance

This project was built by voice dictation with Wispr Flow, into a coding agent, with
**Auto Cleanup set to None** for the whole build. That setting is the tool's own
recommendation, applied to its own construction.

This file exists so nobody has to take that on trust. It records what was dictated, what was
scaffolding, and what the dictation did on the way in.

committed as separate dictation-driven corrections, and each is described below.

## What was scaffolding

Set up before the first dictated instruction, and not part of the claim:

- `pyproject.toml`, `.gitignore`, `SPEC.md`
- the virtualenv and the `mlx-whisper` / `ocrmac` installs
- the evidence corpus `fixtures/corpus.json` and `fixtures/CORPUS.md`

The corpus is the one place where the agent wrote prose rather than receiving dictation.
It is also the part of the project that was **not** generated by the project: the three
captures are the user's voice, and the Scratchpad notes are Wispr Flow's output, read back
over MCP unmodified.

## Corruption log

The most useful artifact in this repository. Six dictated instructions, and what the
dictation did to them:

| Target | Arrived as |
|---|---|
| `src/passthru/scratchpad.py` | `source/pass through/slash scratchpad.py` |
| `src/passthru/score.py` | `source/pass through/score.py` |
| `src/passthru/align.py` | `source/pass through/align.py` |
| `src/passthru/constraints.py` | `source/pass_through/constants.py` |
| `src/passthru/report.py` | `source/pass through/report.py` |
| `src/passthru/advice.py` | `source/pass through/advice.py` |
| `src/passthru/cli.py` | `source/passthrough/cli.py` |

The project name was corrupted three distinct ways across six steps — `pass through`,
`pass_through`, `passthrough`. Each is a syntactically valid directory name.

Two corruptions changed meaning rather than spelling:

- **`constraints` → `constants`.** Different modules. Following the text literally would
  have produced a file that compiles and answers the wrong question.
- **200-`line` limit → 200-`inline` limit.** Nonsense on its face.

Cleaner in later steps, which is worth noting rather than hiding: `200 line limit` came
through intact at one point, and `advise` became `advice`. The corruption rate is not
constant across a single session with constant settings.

**In every case the instruction was ambiguous enough to require interpretation, and in
every case interpreting it wrongly would have produced a plausible, broken artifact.** No
corruption announced itself. That is the argument for measuring every prompt rather than
trusting the pipeline.

## Bugs the corpus caught

Five defects surfaced because each dictated module was verified against real captured
speech, not because a test suite existed:

1. **Trailing punctuation fused to tokens.** `score.py.` did not equal `score.py`, so the
   tool's own central case, a surviving filename, was reported as lost. Appeared twice,
   in two modules.
2. **Greedy sentence boundary.** Any period ended a sentence, so a keep-constraint
   truncated at the dot inside `score.py`.
3. **False-positive loss reporting.** Stopword-stripped values were substring-matched
   against raw prose, so intact requirements were reported lost. A tool that cries wolf
   about requirements that survived is worse than no tool.
4. **Cumulative output column.** The received slice started at offset zero, so every
   utterance's "arrived" cell repeated all preceding text.
5. **Out-of-bounds index.** A `replace` alignment span indexed the received side by spoken
   offset and overran the span.

Fixes 1, 3, and 4 changed measured numbers. They are stated in the commit messages rather
than quietly absorbed.

## What is not claimed

- The three captures are n=1 per setting. They show an effect, not a distribution.
- Reading pace was not matched across runs. Uncontrolled.
- The spoken side is the known script; a separate local ASR engine read the same audio and
  disagreed with Wispr in both directions. Neither is treated as ground truth here, and
  that disagreement is itself part of the finding.
